# TouchDesignerProjects
A collection of small TouchDesigner tools, examples, and reusable projects that I created and would like to share with others. 
Feel free to explore, reuse, modify, and build upon them.

- **BasicProjectionMatrices** A simple and reusable TD project implementing perspective and orthographic projection matrices.
- **KooimaProjectionMatrix** A simple implementation of Kooima's algorithm for tracked camera screen reprojection
